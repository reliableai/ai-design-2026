Setup

  • Python 3.10+ and a working environment for the labs / repo
  • Access to an LLM API (or internal gateway) with a small experimentation budget
  • Ability to run evaluations locally and in CI (preferred)

Budget guidance: add your org’s preferred monthly cap per participant and how to request increases.

Data, privacy, and confidentiality

  • No sensitive data in third-party prompts unless explicitly approved.
  • Prefer sanitized datasets, synthetic examples, and redacted logs.
  • Define the boundary up front: what data is allowed, where it can run, and retention rules.
  • For tool actions (write operations), use least privilege and explicit allowlists.

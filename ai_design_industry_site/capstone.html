Capstone (Production Sprint)

Build something real — and make it measurable, operable, and safe to ship.

Teams: 1–4 (recommended 2–3) Weeks: 6–12 Deliverables > grades

Choose a track

Track A — Shared system

  • Well-scoped problem with baseline components
  • Faster start; better cross-team comparisons
  • Great for mixed-experience cohorts

Track B — Bring your own use case

  • Build for a real team/customer workflow
  • Requires a data boundary and risk review up front
  • Best when you want immediate internal impact

Minimum requirements

System

  • A functional AI application with a clear user journey
  • Integration of agents, tools, and/or memory (if appropriate)
  • Error handling and safe fallbacks (timeouts, tool failures, bad inputs)
  • Basic observability (structured logs + key metrics)
  • Safety considerations and guardrails for actions and data

Evaluation

  • Golden dataset with coverage rationale and labels/rubrics
  • Scorecard with 3–6 quality dimensions tied to product outcomes
  • Evaluation harness runnable locally and in CI
  • At least one ablation/comparison (model/prompt/retrieval/tool strategy)
  • Systematic error taxonomy with examples
  • Uncertainty notes (confidence intervals or clearly stated limitations)

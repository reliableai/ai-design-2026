Who this is for

Great fit

  • Software engineers building AI features into existing products
  • ML / applied AI engineers responsible for quality, evaluation, and deployment
  • Tech leads & architects making system and vendor decisions
  • PMs & designers who own requirements, UX, and ship/no-ship decisions
  • Security/privacy partners supporting AI rollouts

Not the focus

  • Training large models from scratch
  • Pure prompt-writing without instrumentation or evaluation
  • Research-only content without production constraints

What you’ll take back to work

The goal is not a demo — it’s a small production-ready system plus the artifacts that make it safe to ship and easy to improve.

System

  • Working AI feature (agent/tool/memory where appropriate)
  • Clear UX + failure modes + safe fallbacks
  • Integration patterns that don’t turn into “prompt soup”

Measurement & operations

  • Golden dataset + scorecard (multiple quality dimensions)
  • Evaluation harness runnable locally and in CI
  • Observability: logs/metrics/traces + runtime “business assertions”
  • Runbook: rollout/rollback, monitoring, and incident response

See Capstone for the full artifact checklist and review cadence.

How the program is organized

Module 1 — Agentic primitives

  • LLM APIs, streaming UX, memory economics
  • Tool calling and the agent loop
  • When agents are the wrong tool

Module 2 — Evals-first iteration

  • Golden datasets and rating rubrics
  • LLM-as-judge and uncertainty
  • Error taxonomies and iteration discipline

Module 3 — Scaling complexity safely

  • Decomposition, councils/ensembles, interfaces
  • Middleware & connectors (incl. MCP-style)
  • Framework decisions without hype

Module 4 — Capstone sprint

  • Build → evaluate → harden → present
  • Design clinics and reviews
  • Retro + productionization roadmap

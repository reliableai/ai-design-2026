Schedule

A practitioner-friendly schedule with explicit “ship-by” outcomes each week.

12 weeks · 24 sessions compressible into modules capstone runs weeks 6–12

Tip: If you’re running a shorter cohort, combine adjacent sessions (e.g., S1+S2, S5+S6, S9+S10) and keep the ship-by outcomes.

Session plan

WeekSessionTopicShip-by (end of week)
1 S1 Hello World — connecting to AI via API (chat/streaming/voice/image) Baseline client + logging + first cost/latency measurements
1 S2 Stateful Clients — context & session memory, cost/latency tradeoffs Memory strategy + explicit cost/latency budgets
2 S3 Tools & the Agentic Loop — tool calling, orchestration, AI controlling UX Tool prototype + safe tool boundary rules
2 S4 Monitoring & Business Assertions — observability, runtime checks, evaluating executions First scorecard draft + runtime “assertions”
3 S5 Quality & Performance Estimation — metrics, golden datasets, LLM-as-judge, uncertainty Golden dataset v0 + evaluation harness skeleton
3 S6 Iterating on Clients, Agents & Prompts — experiment design, error analysis Error taxonomy v0 + prioritized experiment backlog
4 S7 Councils of Agents — eliciting diversity, ensemble and consensus mechanisms One ensemble/consensus experiment (even if it fails)
4 S8 Building Complex Systems — decomposition, separation of concerns, APIs vs interfaces Decomposition diagram + interface boundaries
5 S9 Middleware, Abstractions & Interfaces — MCP-style connectors, privacy, guardrails Connector/tool spec + contract tests for tools
5 S10 Structuring Complex Projects — versioning prompts/configs/evals Regression plan for prompts + evaluation versioning
6 S11 AI Frameworks — when/why to use frameworks (LangChain as a case study) Make-vs-buy decision record + migration plan (if adopting)
6 S12 Capstone kickoff — scope, risks, and milestones Capstone spec v1 + evaluation plan v1
7 S13 Readiness review — design & evaluation readiness Risk register + ship criteria + success metrics
7 S14 Capstone review #1 — architecture and eval validity Architecture diagram + golden dataset plan
8 S15 Working session — implementation End-to-end “happy path” in a realistic environment
8 S16 Working session — evaluation First full evaluation run + results summary
9 S17 Mid-project demo — what works, what breaks, what’s next Demo + updated risks + next iteration plan
9 S18 Design clinic — architecture / eval / safety breakouts Close top 3 production risks (plan + owners)
10 S19 Integration & hardening — fallbacks, guardrails, tracing Safe mode + tool safeguards + core monitoring dashboards
10 S20 Final evaluation runs — ablations and comparative experiments Reproducible results package + confidence/uncertainty notes
11 S21 Results review — narrative and tradeoffs Report draft + “what we’d ship vs not ship” summary
11 S22 Presentation rehearsal — executive-ready readout Slides + demo script + Q&A prep
12 S23 Final demos Live demo + scorecard + rollout/rollback plan
12 S24 Retrospective Postmortem + next-30-days productionization plan

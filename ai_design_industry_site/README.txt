AI Design 2026 — Industry Edition (HTML pack)
============================================

Files:
- index.html         Overview landing page
- schedule.html      Session plan with ship-by outcomes
- capstone.html      Capstone requirements + review cadence
- deliverables.html  Completion checklist (no grades)
- logistics.html     Setup, support, privacy/safety agreements
- assets/styles.css  Styling (single file, no external deps)
- assets/site.js     Mobile nav + active link highlighting

How to use:
1) Copy this folder into your static site hosting (GitHub Pages, S3, etc.)
2) If you want to host inside the existing ai-design-2026 repo, drop these at the root next to the other pages.
3) Replace placeholders like [Company], [Dates], [Slack link].

Notes:
- Links to labs use relative paths like labs/... so they will work if you keep the same repo structure.
- If you host these elsewhere, update those links to point to the original site.
